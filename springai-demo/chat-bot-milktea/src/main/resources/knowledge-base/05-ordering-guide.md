# 栖叶茶事·青禾里店｜点单规则与常见问题

本页为虚构门店的演示规则，适用于栖叶茶事·青禾里店。

## 杯型、价格和线上结算

栖叶茶事·青禾里店的中杯标称容量为 500 mL，大杯为 650 mL。蜜柚气泡饮仅有中杯。饮品菜单列出门店单杯基础价，线上实付以结算页为准，可能包含优惠、包装费或配送费。库存和优惠资格以当前下单页面为准。

## 糖度和冰量怎么选

支持调糖的饮品可选正常糖、半糖、少糖或不另外加糖。「不另外加糖」表示制作时不另加糖浆，鲜牛奶、果肉和黑糖珍珠本身可能有甜味。草莓鲜乳和蜜柚气泡饮采用固定糖度。

热饮仅在菜单标注可选热饮的商品中提供。去冰是在冰饮制作完成后去掉冰块，成品仍可能是凉的。蜜柚气泡饮仅可选正常冰或少冰，其他冰饮的冰量选项以各商品为准。

## 加料种类和费用

鲜奶茶及无茶底的鲜乳饮品可加黑糖珍珠或椰果，鲜果茶只可加椰果。蜜柚气泡饮不支持加料。黑糖珍珠每份 3 元，椰果每份 2 元。默认带珍珠的两款黑糖饮品已经包含一份珍珠，额外再加一份按加料价收费。例如，16 元的中杯茉白鲜奶茶加一份黑糖珍珠，门店饮品价合计 19 元。

## 按口味选饮品

偏好淡奶味和花香，可以选茉白鲜奶茶或桂香轻乳茶。想喝茶味较重的奶茶，可以选焙乌龙鲜奶茶。偏好酸爽果茶，可以选手打青柠乌龙。想要带珍珠的无茶底饮品，可以选黑糖珍珠鲜乳。想要无茶底且默认配方不加奶的饮品，可以选蜜柚气泡饮。

## 配料、过敏原和替换

鲜奶茶、黑糖珍珠鲜乳和草莓鲜乳使用鲜牛奶，门店不提供植物奶替换。鲜果茶和蜜柚气泡饮的默认配方不加牛奶，制作区域和器具为门店共用。如需核实配料或交叉接触情况，可在下单前请门店工作人员确认。
