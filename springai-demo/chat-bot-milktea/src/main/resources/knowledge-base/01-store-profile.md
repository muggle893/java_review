# 栖叶茶事·青禾里店｜门店介绍

本文是奶茶客服演示项目的虚构资料。门店、地址、菜单、价格、点单渠道和服务规则均为示例设定。

## 门店名称和特色

栖叶茶事·青禾里店是位于广州天河区的现制茶饮门店，简称「栖叶茶事青禾里店」或「青禾里店」。门店供应鲜奶茶、鲜果茶和无茶底饮品。鲜奶茶侧重茶香与鲜奶的搭配，鲜果茶以柑橘、葡萄和青柠等果味为主。招牌饮品是茉白鲜奶茶，门店也提供带黑糖珍珠的饮品。

## 地址和到店方式

栖叶茶事·青禾里店的示例地址为广州市天河区青禾里示范街 18 号一层 103 铺。示例门店位于青禾里商业街东门内，靠近一层中庭。门店支持到店自取，店内设有等候区和少量座位。

## 营业时间和服务时段

栖叶茶事·青禾里店每日 10:00 至 22:00 营业，堂食和自取的最后下单时间为 21:30。外卖接单时段为 10:30 至 21:00，配送范围和预计送达时间以外卖平台结算页为准。节假日临时调整以门店公告或下单页面为准。

## 下单渠道和客服入口

栖叶茶事·青禾里店支持在门店柜台点单，也可在「栖叶茶事」示例小程序下单自取。外卖请通过配送平台的「栖叶茶事·青禾里店」页面下单。到店自取时，可出示小程序订单页上的取餐码或柜台小票。外卖配送和售后可通过原下单平台的订单页联系客服。
